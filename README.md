# Sami Azraf — 3D Animated Portfolio

A modern, single-page portfolio website built from Sami Azraf's CV, featuring:

- **Three.js 3D particle & geometric background** with mouse parallax
- Smooth scroll sections, typing animation, glassmorphism cards
- 3D tilt effect on project cards
- Fully responsive design
- Dark tech aesthetic

## Contents

| Section        | Content                                      |
|----------------|----------------------------------------------|
| Hero           | Name, photo, typing titles, social links     |
| Education      | BUP CSE, HSC, SSC                            |
| Skills         | Languages, Backend, Frontend, IoT, Tools     |
| Projects       | Food Waste Tracker, Movie Tracker, ScholarForum, Review Summarizer |
| Achievements   | Hackathons & ICPC placements                 |
| Activities     | Programming Club & IEEE BUP                  |
| Contact        | Email, phone, address, references            |

## How to run

Simply open `index.html` in a modern browser, or serve locally:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.

## Tech stack

- HTML5 / CSS3 (custom properties, glassmorphism, animations)
- Vanilla JavaScript
- Three.js (r128) for 3D background
- Google Fonts (Inter + Space Grotesk)
- Font Awesome icons

No build step required.
